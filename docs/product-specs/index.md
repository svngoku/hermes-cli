## How to add a spec

Create `docs/product-specs/<feature-slug>.md` describing the user problem,
desired behaviour, acceptance criteria, and any UI/flow diagrams (use Mermaid).
Then add a row above and, when implementation starts, create a matching
exec-plan in [`../exec-plans/active/`](../exec-plans/active/).
